第41章 · GESP C++四级 必背编程真题

GESP C++ 四级上机固定为「客观题 40 分 + 2 道编程大题各 25 分」。编程大题的高频母题集中在 结构体与排序、二维数组与网格、递推、字符串与数位模拟、函数封装，偶尔涉及指针、文件重定向与异常处理。

第49章 栈、队列与循环队列

考核目标：掌握栈、队列、循环队列的基本定义、应用场景与常见操作；能根据实际问题的特点，选择合适的数据结构。

第50章 树

考核目标：掌握树的基本概念、术语与特性；能分辨不同的树结构；理解树的多种表示方法，并掌握先根、后根、层次等遍历算法。

第51章 哈夫曼树

考核目标：理解哈夫曼树（最优二叉树）的定义与"带权路径长度最短"的含意；掌握其贪心构造方法；理解哈夫曼编码作为前缀码的原理，能进行简单应用。

第52章 完全二叉树和二叉排序树

考核目标：掌握完全二叉树的结构特性与数组存储（父子下标关系）；掌握二叉排序树（BST）的定义、中序有序特性，以及查找、插入、删除等核心操作。

第53章 格雷编码

考核目标：理解格雷编码"相邻仅一位不同、首尾也仅一位不同"的特性；掌握二进制与格雷码之间的相互转换；能用代码生成格雷码序列。

第54章 二叉树的搜索算法

考核目标：掌握深度优先搜索（DFS，含先/中/后序）与广度优先搜索（BFS，层次遍历）的思想；能根据实际问题（目标在浅层还是深层、是否求路径）选择合适的搜索算法。

第55章 简单动态规划

考核目标：掌握动态规划的核心思想（最优子结构、重叠子问题、状态转移方程、边界条件）；能使用代码解决一维动态规划问题（如斐波那契、爬楼梯、最大子数组和）与简单背包问题（0/1 背包、完全背包）。

第56章 面向对象编程

考核目标：掌握面向对象的基本思想（与面向过程对比）；掌握类的定义、对象的创建与初始化（构造函数）；理解并会使用封装、继承、多态三大特性。

第57章 常用数学函数

标准数学库(math.h或cmath)提供了丰富的数学计算函数，其中三角函数、对数函数和指数函数是编程中处理几何、科学计算问题的基础工具。

第58章 复杂动态规划

复杂动态规划是在基础一维动态规划之上的扩展，主要包括二维动态规划及动态规划最值优化策略。二维动态规划通过二维状态数组描述问题，适用于处理具有两个维度约束的场景（如矩阵路径、区间问题等）；最值优化则通过对状态转移方程的分析，减少冗余计算，提升算法效率。

第59章 图的定义及基本图论算法

图（Graph）是一种比线性表和树更复杂的非线性数据结构，由顶点（Vertex）和边（Edge）组成，能够描述多对多的复杂关系，在社交网络、路线规划、电路设计、图像处理和迷宫求解等领域都有广泛应用。

第60章 哈希表

哈希表(Hash Table)，又称散列表，是一种通过哈希函数将键(Key)映射到值(Value)的高效数据结构。它能够在平均情况下实现$$O(1)$$时间复杂度的插入、删除和查找操作，是解决查找问题的最优选择之一。

第61章 必备编程模板（GESP 七级真题实战）

本章把 GESP C++ 七级（2023-12 至 2026-06 历年真题）里反复出现的编程题，提炼成一套"背下来就能改"的核心模板。每一节都是一个可直接编译运行的 C++ 程序骨架，并标注它对应哪道真题。把这一章熟记、能手写，七级编程题（每场 2 道、共 50 分）基本就能稳过。
