第44章 线性表和链表

线性表是计算机科学中最基础、最常用的数据结构之一，它是由 $n$ 个具有相同特性的数据元素组成的有限序列。本章对应 GESP C++ 五级知识块 4：链表，要求掌握单链表、双链表、循环链表的创建、插入、删除、遍历、查找、反转等基本操作，并理解三者的区别。

第8章 线性数据结构

线性数据结构是 CSP-S 复赛与初赛的共同核心：数组、链表、栈、队列、哈希表、字符串。复赛中栈（递归/表达式/DFS）、队列（BFS）、哈希表（判重/计数）、字符串（模式/前缀）几乎每场必考；初赛则偏好考"概念辨析 + 计算"（哈希冲突、子串数、出栈序列、复杂度）。
