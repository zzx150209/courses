第1章 计算机基础知识

本章介绍学习 C++ 编程前需要了解的计算机关底知识：计算机的发展、冯·诺依曼体系结构、硬件与软件组成、分类与应用，以及程序是如何被"翻译"成机器能懂的语言的。这些概念是 GESP 一级选择题的高频考点。

第2章 C/C++ 集成开发环境与程序开发流程

要运行 C++ 程序，我们需要一个 IDE（集成开发环境）。本章介绍常用 IDE、Dev-C++ 的使用、一个程序从写下到运行的完整流程，以及代码注释的写法。

第3章 数据类型、变量与常量

程序处理的每一个数据都必须先"声明类型"。本章讲解 C++ 一级要求的基本数据类型、变量的定义与命名规则、常量的两种写法，以及字符背后的 ASCII 码。

第4章 程序的输入和输出

程序需要把结果"输出"给用户，也需要从用户那里"输入"数据。C++ 提供 cin/cout，C 语言提供 printf/scanf。本章逐一讲解，并重点说明格式化输出与常见陷阱。

第5章 运算符与表达式

表达式 = 运算符 + 操作数 + 括号，运算后得到一个结果值。本章覆盖 GESP 一级要求的全部运算符，并强调几个最容易出错的细节。

第6章 程序基本控制结构

程序的三大基本结构：顺序、分支、循环。本章先讲分支（根据条件走不同路），再讲循环（重复做一件事），最后讲 break/continue 对循环的控制。

第7章 数组与字符串

当需要处理"一堆同类型的数据"（如一个班的 50 个成绩）时，一个个定义变量太麻烦。数组就是用"一个名字 + 下标"管理一批数据；字符串则是字符的序列。本章讲解一维数组与 C++ 的 string 字符串。

第8章 简单算法与数学

本章是 GESP 一级的"算法入门"：进制转换、素数判断、最大公约数/最小公倍数、数位分离，以及把上述技巧组合起来的简单模拟题。

一级必背编程模板（编程题通关）

本章把 GESP C++ 一级（2023–2025 全部公开机试真题 + 2026 高频押题）按题型归纳成 12 个必背代码模板。每个模板都给出可直接提交的完整程序（C++17、4 空格缩进、关键行带注释），配上大白话讲解和易错警告。背熟这 12 个模板，一级编程题（2 道 ×25 分 = 50 分）基本稳过。
