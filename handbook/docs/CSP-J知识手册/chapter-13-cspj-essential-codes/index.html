CSP-J 复赛必备编程模板（核心代码速查）

本文把近十年 CSP-J（含 NOIP 普及组）复赛反复出现的核心算法整理成"背下来就能套"的代码模板。 所有代码均为 C++17，可直接复制使用；约定数组大小 N 按题目数据范围取够，INF 表示无穷大（0x3f3f3f3f）。

一句话：T1 / T2 拼细节与模板熟练度，T3 / T4 拼"认得出题型 + 套对模板"。把下面这些代码背熟、能默写、能在考场上 5 分钟调通，复赛编程题基本稳过。

一、考场约定与万能骨架

1.1 万能头文件 + 快读快写

复赛允许用 #include <bits/stdc++.h>，省去记一堆头文件。当 cin/cout 超时（大数据量）时改用 scanf/printf，或下面这套快读。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int INF = 0x3f3f3f3f;
const ll LLINF = 0x3f3f3f3f3f3f3f3f;   // long long 版"无穷大"（约 4.5e18，当 INF 用足够）

// 快读（整数，支持 long long 与负数）
ll read() {
    ll x = 0, f = 1; char c = getchar();
    while (c < '0' || c > '9') { if (c == '-') f = -1; c = getchar(); }
    while (c >= '0' && c <= '9') { x = x * 10 + c - '0'; c = getchar(); }
    return x * f;
}

// 快写（整数，支持 long long 与负数）
void write(ll x) {
    if (x < 0) { putchar('-'); x = -x; }
    if (x > 9) write(x / 10);
    putchar(x % 10 + '0');
}

int main() {
    cin.tie(0)->sync_with_stdio(0);   // 关闭同步+解绑，给 cin/cout 提速（等价于 ios::sync_with_stdio(false); cin.tie(nullptr);）
    ll n = read();
    write(n);
    return 0;
}
背什么 / 怎么用
  • cin.tie(0)->sync_with_stdio(0); 放在 main 开头即可给 cin/cout 提速（等价于 ios::sync_with_stdio(false); cin.tie(nullptr);）；用 read()/write() 这套快读写则无需解绑，且速度更快。
  • LLINF = 0x3f3f3f3f3f3f3f3f 是 long long 版无穷大，够当 INF 用；若真要 long long 上界，用 0x7fffffffffffffff（即 LLONG_MAX）。
  • using ll = long long; 之后，凡是可能爆 int 的（乘积、阶乘、路径和）一律用 ll；这里 read() 已返回 ll，正负都能读。

二、数学与数论基础（最高频）

2.1 最大公约数 GCD / 最小公倍数 LCM

ll gcd(ll a, ll b) {
    return b == 0 ? a : gcd(b, a % b);
}
ll lcm(ll a, ll b) {
    return a / gcd(a, b) * b;   // 先除后乘，防溢出
}
对应真题
  • 2014 比例简化（枚举 + gcd 约分）
  • 2001 最大公约数和最小公倍数问题

2.2 快速幂（带取模）

ll qpow(ll a, ll b, ll mod) {
    ll res = 1 % mod;
    a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
背什么 / 怎么用
  • 求 a^b % mod、逆元（qpow(a, mod-2, mod)，要求 mod 为质数）、大数乘模都靠它。
  • 口诀：指数 b 看成二进制，遇到 1 就乘进答案，每轮底数自乘、指数右移。

2.3 质数判断

bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * 1LL * i <= x; i++)
        if (x % i == 0) return false;
    return true;
}

2.4 埃氏筛 / 欧拉筛

// 埃氏筛：标记合数
const int N = 1000005;
bool isp[N];
void sieve(int n) {
    for (int i = 2; i <= n; i++) isp[i] = true;
    for (int i = 2; i * 1LL * i <= n; i++)
        if (isp[i])
            for (int j = i * i; j <= n; j += i) isp[j] = false;
}

// 欧拉筛：线性，prime[] 里存所有素数
int prime[N], cnt;
bool notPrime[N];
void euler(int n) {
    for (int i = 2; i <= n; i++) {
        if (!notPrime[i]) prime[++cnt] = i;
        for (int j = 1; j <= cnt && i * 1LL * prime[j] <= n; j++) {
            notPrime[i * prime[j]] = true;
            if (i % prime[j] == 0) break;   // 关键：保证每个合数只被最小质因子筛掉
        }
    }
}

2.5 进制转换

// 十进制 n 转 radix 进制字符串（radix 任意，支持到 36）
string toBase(ll n, int radix) {
    if (n == 0) return "0";
    string s;
    while (n) {
        int d = n % radix;
        s += (d < 10 ? char(d + '0') : char(d - 10 + 'A'));
        n /= radix;
    }
    reverse(s.begin(), s.end());
    return s;
}

// radix 进制字符串 s 转十进制
ll fromBase(const string &s, int radix) {
    ll res = 0;
    for (char c : s) {
        int d = isdigit(c) ? c - '0' : toupper(c) - 'A' + 10;
        res = res * radix + d;
    }
    return res;
}
对应真题
  • 2020 优秀的拆分（二进制拆分，位运算）
  • 2011 数字反转（十进制反转）
  • 2006 数列（进制转换）

4.4 并查集

const int N = 100005;
int fa[N];
void init(int n) { for (int i = 1; i <= n; i++) fa[i] = i; }
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); } // 路径压缩
void merge(int x, int y) { fa[find(x)] = find(y); }
bool same(int x, int y) { return find(x) == find(y); }
怎么用
  • 判断"两个元素是否在同一集合"、合并集合、求连通块个数。
  • 最小生成树 Kruskal 必用（见第七节），连通性判定、团伙分组题也常用。

五、搜索（DFS / BFS / 回溯）

5.1 DFS 模板（含回溯）

bool vis[N];
void dfs(int step) {
    if (step == n) { /* 到达边界：输出 / 统计答案 */ return; }
    for (int i = 0; i < m; i++) {
        if (!vis[i]) {            // 选 i 的合法性检查
            vis[i] = true;
            dfs(step + 1);
            vis[i] = false;       // 回溯：撤销选择
        }
    }
}

5.2 全排列枚举（next_permutation）

5.3 组合枚举（DFS 选 k 个）

int ans[15];
void dfs(int pos, int last, int k) {  // 从 last+1 开始选 k 个，不重复
    if (pos == k) { /* 输出 ans[0..k-1] */ return; }
    for (int i = last + 1; i <= n; i++) {
        ans[pos] = i;
        dfs(pos + 1, i, k);
    }
}

5.4 BFS 模板（最短路 / 扩散）

#include <queue>
struct Node { int x, y, step; };
queue<Node> q;
q.push(start); vis[start.x][start.y] = true;
while (!q.empty()) {
    Node u = q.front(); q.pop();
    for (每个相邻位置 v) {
        if (合法且 !vis[v]) {
            vis[v] = true;
            dist[v] = dist[u] + 1;   // 第一次到达即最短
            q.push(v);
        }
    }
}

6.5 最长公共子序列 LCS

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        if (s1[i] == s2[j]) f[i][j] = f[i - 1][j - 1] + 1;

6.6 一维线性 DP 套路

// 通用框架：dp[i] 表示"以第 i 个位置结尾"的最优值
for (int i = 1; i <= n; i++) {
    dp[i] = 初值;
    for (int j = 1; j < i; j++)
        if (满足条件) dp[i] = 最优(dp[i], dp[j] + 增量);
}
怎么用
  • "求最长 / 最大 / 最小"类题，先想 dp[i] 表示什么，再找转移：从前面哪些 j 能转移过来。
  • 2024 接龙、2018 摆渡车本质都是线性 DP，认出"状态 + 转移"就能套。

7.2 Dijkstra 最短路（朴素 O(n²)，小图适用）

const int N = 1005;
int g[N][N], dist[N], vis[N];
void dijkstra(int s, int n) {
    memset(dist, 0x3f, sizeof dist);
    dist[s] = 0;
    for (int i = 1; i <= n; i++) {
        int u = -1, mn = INF;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && dist[j] < mn) { mn = dist[j]; u = j; }
        if (u == -1) break;
        vis[u] = true;
        for (int v = 1; v <= n; v++)
            if (!vis[v]) dist[v] = min(dist[v], dist[u] + g[u][v]);
    }
}
// 注意：邻接矩阵 g 先全部置 INF，g[i][i] = 0
对应真题
  • 2023 旅游巴士（最短路 + 限制条件）
  • 2019 加工零件（奇偶层最短路）

7.3 Floyd 最短路（多源，O(n³)）

const int N = 205, INF = 0x3f3f3f3f;
int d[N][N];
// 初始化 d[i][j] = 边权，d[i][i] = 0，无直接边置 INF
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (d[i][k] < INF && d[k][j] < INF)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);

7.4 Kruskal 最小生成树

struct Edge { int u, v, w; } e[N];
bool cmp(const Edge &a, const Edge &b) { return a.w < b.w; }
int kruskal(int n, int m) {     // n 个点 m 条边
    sort(e + 1, e + m + 1, cmp);
    init(n);                    // 调用并查集初始化
    int sum = 0, cnt = 0;
    for (int i = 1; i <= m; i++) {
        int u = e[i].u, v = e[i].v;
        if (!same(u, v)) {
            merge(u, v);
            sum += e[i].w;
            cnt++;
        }
        if (cnt == n - 1) break;  // 已选够 n-1 条边
    }
    return sum;   // 若 cnt < n-1 则图不连通
}

7.5 树的遍历（DFS）

vector<int> g[N];
void dfs(int u, int fa) {       // fa 是父节点，防止走回头
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
    }
}
对应真题
  • 2018 对称二叉树（递归比较左右子树）

八、高精度与组合数学

8.1 高精度加法（字符串）

string add(const string &a, const string &b) {
    string s;
    int i = a.size() - 1, j = b.size() - 1, c = 0;
    while (i >= 0 || j >= 0 || c) {
        int x = i >= 0 ? a[i--] - '0' : 0;
        int y = j >= 0 ? b[j--] - '0' : 0;
        s += char((x + y + c) % 10 + '0');
        c = (x + y + c) / 10;
    }
    reverse(s.begin(), s.end());
    return s;
}
对应真题
  • 2005 循环（大数幂次位数 / 高精度）
  • 2003 麦森数（高精度求末 500 位）

8.2 高精度减法（字符串，约定 a ≥ b）

string sub(const string &a, const string &b) {
    // 约定 a >= b；若 a < b 需先比较大小、交换并记负号
    string s;
    int i = (int)a.size() - 1, j = (int)b.size() - 1, c = 0;
    while (i >= 0 || j >= 0) {
        int x = i >= 0 ? a[i--] - '0' : 0;
        int y = j >= 0 ? b[j--] - '0' : 0;
        int d = x - y - c;
        if (d < 0) { d += 10; c = 1; }   // 借位
        else c = 0;
        s += char(d + '0');
    }
    reverse(s.begin(), s.end());
    int k = 0;
    while (k + 1 < s.size() && s[k] == '0') k++;   // 去前导 0，保留一位
    return s.substr(k);
}
怎么用
  • 减法要求被减数 ≥ 减数；若 a < b，先比较大小再交换，结果加负号。
  • 借位标记 c 参与下一位运算；最后去前导 0（结果本身是 0 时保留一个 '0'）。

8.3 高精度乘法（字符串）

string mul(const string &a, const string &b) {
    int n = a.size(), m = b.size();
    vector<int> c(n + m, 0);
    for (int i = n - 1; i >= 0; i--)
        for (int j = m - 1; j >= 0; j--)
            c[i + j + 1] += (a[i] - '0') * (b[j] - '0');
    for (int i = n + m - 1; i > 0; i--) {
        c[i - 1] += c[i] / 10;
        c[i] %= 10;
    }
    int k = 0;
    while (k < n + m - 1 && c[k] == 0) k++;
    string s;
    for (int i = k; i < n + m; i++) s += char(c[i] + '0');
    return s;
}

8.4 高精度除法（高精 ÷ 低精整数）

// a 为高精度字符串，b 为 int 范围除数（b > 0），余数通过 rem 返回
string div(const string &a, int b, int &rem) {
    string s;
    ll cur = 0;
    for (char ch : a) {
        cur = cur * 10 + (ch - '0');
        s += char(cur / b + '0');
        cur %= b;
    }
    rem = (int)cur;                 // 最终余数
    int k = 0;
    while (k + 1 < s.size() && s[k] == '0') k++;   // 去前导 0
    return s.substr(k);
}
怎么用
  • 这是"高精 ÷ 低精"模板，覆盖 CSP-J 绝大多数场景（大数整除、进制转换、求商与余数）。
  • 用 long long 的 cur 暂存当前位，避免中间值溢出；rem 即最终余数。
  • "高精 ÷ 高精"本质是反复减法试商，考场极少见，不必背。

8.5 组合数 / 杨辉三角

const int N = 2005, MOD = 1e9 + 7;
ll C[N][N];
void comb(int n) {                 // 预处理 C[n][k]
    C[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        C[i][0] = 1;
        for (int j = 1; j <= i; j++)
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD;
    }
}

8.6 字符串哈希（滚动哈希）

const ll B = 131, MOD = 1e9 + 7, N = 100005;
ll h[N], p[N];
void build(const string &s) {
    p[0] = 1; h[0] = 0;
    for (int i = 0; i < s.size(); i++) {
        p[i + 1] = p[i] * B % MOD;
        h[i + 1] = (h[i] * B + s[i]) % MOD;
    }
}
ll sub(int l, int r) {             // 1-based 闭区间 [l, r] 的子串哈希
    return (h[r] - h[l - 1] * p[r - l + 1] % MOD + MOD) % MOD;
}
怎么用
  • 快速判断两段子串是否相等（哈希值相等即相等，冲突概率极低）。
  • 字符串去重、最长公共子串、Rabin-Karp 匹配都用它。

九、字符串处理速查

9.1 回文判断 / 双指针

bool isPal(const string &s) {
    int i = 0, j = (int)s.size() - 1;
    while (i < j) {
        if (s[i] != s[j]) return false;
        i++; j--;
    }
    return true;
}
对应真题

9.2 字符统计 / 子串

string s;
cin >> s;
// 字符频率
int cnt[256] = {0};
for (char c : s) cnt[(unsigned char)c]++;
// 查找子串
size_t pos = s.find("abc");
if (pos != string::npos) { /* 找到，pos 是下标 */ }
// 取子串 [l, r]（长度 = r - l + 1）
string sub = s.substr(l, r - l + 1);
易错点
  • cin >> s 遇空格就停；读整行用 getline(cin, s)，且 cin 后接 getline 要先 cin.ignore() 吃掉换行。
