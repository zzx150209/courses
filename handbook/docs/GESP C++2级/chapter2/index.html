第10章 计算机网络知识

计算机网络是将多台独立计算机通过通信线路相连，在网络协议管控下实现资源共享、信息传输的系统。本章讲解网络分层、IP、域名、HTML 基础。

10.1 网络体系结构

10.1.1 OSI 七层模型（国际标准）

自下而上：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层

  1. 物理层：传输原始比特流，网线、光纤、网卡硬件规范；
  2. 数据链路层：比特封装成帧，差错校验，以太网协议；
  3. 网络层：路由寻址，核心协议 IP，跨主机传输；
  4. 传输层：端到端进程通信，TCP、UDP；
  5. 会话层：建立/断开应用会话、同步；
  6. 表示层：数据编码、加密、格式转换；
  7. 应用层：面向用户程序，HTTP、FTP、SMTP。

10.1.2 TCP/IP 四层模型（实际工业标准）

合并简化 OSI 分层，自下而上：

  1. 网络接口层（对应 OSI 物理 + 数据链路层）；
  2. 网络层（IP 协议）；
  3. 传输层（TCP、UDP）；
  4. 应用层（融合会话/表示/应用层，HTTP、DNS）。
tip

对应关系速记 OSI 七层太多，TCP/IP 四层是"实用版"：把最上面三层（应用/表示/会话）合并成一层"应用层"，把最下面两层（物理/数据链路）合并成"网络接口层"。考试常问"HTTP 在应用层、IP 在网络层、TCP/UDP 在传输层"。

10.2 IP 地址

IP 是网络主机唯一标识，分 IPv4、IPv6。

10.2.1 IPv4

32 位二进制，4 段十进制（点分十进制），每段 0~255，例 192.168.1.1。

IPv4 地址分类

  • A 类：首字节 1~126，大型网络，掩码 255.0.0.0
  • B 类：首字节 128~191，中型网络，掩码 255.255.0.0
  • C 类：首字节 192~223，小型局域网，掩码 255.255.255.0
  • D 类：224~239，组播专用
  • E 类：240~255，实验保留

子网掩码

区分 IP 里网络位和主机位；二进制 1 代表网络段，0 代表主机段。 例 192.168.1.100 / 255.255.255.0，网络段 192.168.1，主机段 100。

caution

子网划分怎么算 子网掩码中连续的 1 表示网络位。例如 255.255.255.0 写成二进制是前面 24 个 1，所以网络位是前 24 位（前 3 段），主机位是最后 8 位。同一局域网内主机位不同、网络位相同才能互通。

10.2.2 IPv6

128 位，8 组十六进制，解决 IPv4 地址枯竭，地址空间极大。 示例：2001:0db8:85a3:0000:0000:8a2e:0370:7334

10.3 DNS 域名系统

10.3.1 作用

域名 ↔ IP 互相映射，数字 IP 难记，域名（www.xxx.com）便于使用。

10.3.2 域名层级（从右到左）

www.example.com

  • com：顶级域名（商业机构）
  • example：二级域名（企业/组织）
  • www：三级域名（网站服务）

通用顶级域： .com 商业、.org 非营利、.edu 教育、.gov 政府、.cn 中国国家域名。

10.3.3 DNS 解析流程

  1. 浏览器输入域名，先查本机缓存；
  2. 无记录则请求本地 DNS 服务器；
  3. 本地 DNS 无记录 → 查询根服务器；
  4. 根返回顶级域服务器地址；
  5. 逐级查询到权威服务器，获取对应 IP；
  6. IP 返回客户端并缓存，浏览器建立连接。

10.4 HTML 基础

HTML 是网页标记语言，定义页面结构，由标签组成。

10.4.1 标准 HTML5 文档结构

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>网页标题</title>
</head>
<body>
    <!-- 页面可见内容 -->
    <h1>一级标题</h1>
    <p>段落文本</p>
</body>
</html>

10.4.2 常用基础标签

  1. 标题：<h1>~<h6>，h1 最大；
  2. 段落：<p> 自动前后换行；
  3. 超链接：<a href="地址">文字</a>；
  4. 图片：<img src="图片路径" alt="替代文字">；
  5. 无序列表 <ul><li>项</li></ul>；有序列表 <ol>；
  6. 分区 <div> 块容器、<span> 行内容器。

10.4.3 HTML / CSS / JS 分工

  • HTML：页面结构（文字、图片、板块）；
  • CSS：页面样式（颜色、字体、布局）；
  • JavaScript：页面交互（点击、动态更新）。

练习题（2 级单选风格）

  1. 下列 IP 地址书写合法的是？
    • A. 256.1.1.1
    • B. 192.168.1.1
    • C. 192.168.1
    • D. 10.0.0.256
  2. DNS 域名系统的主要功能是？
    • A. 自动分配 IP 地址
    • B. 将域名解析为 IP 地址
    • C. 加密传输数据
    • D. 直接提供网页内容
  3. 覆盖范围局限在一栋楼或一间办公室的网络通常称为？
    • A. WAN
    • B. MAN
    • C. LAN
    • D. Internet
  4. 在 HTML 中，创建超链接使用的标签是？
    • A. <img>
    • B. <a>
    • C. <div>
    • D. <p>
  5. TCP/IP 四层参考模型的最底层是？
    • A. 应用层
    • B. 传输层
    • C. 网络接口层
    • D. 网络层
参考答案（点击展开）
  1. B — IP 地址每个十进制段必须在 0~255 之间，且需 4 段；A、D 出现 256 超限，C 只有 3 段。
  2. B — DNS 把易记的域名（如 www.ccf.org.cn）翻译成机器用的 IP 地址；自动分配 IP 是 DHCP 的职责。
  3. C — LAN（Local Area Network）局域网；WAN 广域网、MAN 城域网。
  4. B — <a href="...">文字</a> 是超链接标签；<img> 是图片、<div> 是分区容器、<p> 是段落。
  5. C — TCP/IP 四层自底向上为：网络接口层 → 网络层 → 传输层 → 应用层。
