info

对应 GESP C++ 2 级知识块①：计算机的存储与网络（存储部分）

官方要求：了解计算机存储的基本概念及分类，了解随机存储器（RAM）、只读存储器（ROM）和高速缓冲存储器（Cache）的功能及区别。

本章讲解存储相关硬件；网络部分（计算机网络分类、TCP/IP 与 OSI、IP 与子网）见第 10 章。

第9章 计算机的架构体系

9.1 计算机的体系结构

现代计算机大多基于冯·诺依曼体系结构，核心思想：

  1. 采用二进制存储数据与指令；
  2. 程序、数据统一存入存储器，可自动读取执行；
  3. 计算机五大核心部件：运算器、控制器、存储器、输入设备、输出设备。
tip

考试怎么考 GESP 选择题常把"五大部件"与"程序指令和数据一起存进存储器"作为考点，记住冯·诺依曼的"存储程序"思想即可。

9.2 CPU（中央处理器）

CPU 是计算机核心，被称为"大脑"，负责执行指令、运算数据。

9.2.1 内部组成

  1. 运算器：完成算术运算（加减乘除）、逻辑运算（与或非）；
  2. 控制器：取指令、解析指令、调度各部件协同工作；
  3. 寄存器：高速临时存储单元，存取速度远超内存，存放 CPU 正在处理的数据/指令。

9.2.2 性能指标

  1. 主频（Hz）：时钟频率，数值越高单位时间执行指令越多，运算越快；
  2. 核心数：多核 CPU 可并行处理多任务，提升并发能力；
  3. 字长：CPU 单次可处理的二进制位数，常见 32/64 位；字长越长寻址、处理能力越强。

9.3 存储器

存储器用于存放程序与数据，按读写速度、断电特性分为缓存、内存、外存。

9.3.1 Cache 高速缓冲存储器

位置：CPU 与内存之间，速度接近 CPU； 作用：缓存 CPU 高频访问数据，减少读取内存的耗时；

  • 命中：Cache 找到数据，直接读取；
  • 未命中：去内存读取并同步存入 Cache；
  • 分级：L1（CPU 内置、最快、容量最小）、L2、L3（容量递增，速度递减）。
caution

易错点 Cache 是"高速缓冲"，不是"主存"；它解决的是 CPU 与内存之间的速度差，断电后数据丢失。选择题里常把 Cache 与 RAM 混在一起考，注意区分层级。

9.3.2 内存（主存）

直接与 CPU 交换数据，速度快、容量偏小，断电数据丢失。

  1. RAM 随机存取存储器：可读可写，日常内存条；分为 DRAM（低成本）、SRAM（高速昂贵）；
  2. ROM 只读存储器：出厂固化数据，断电不丢失，用于 BIOS 开机固件。

9.3.3 外存（辅助存储器）

容量大、价格低、断电数据永久保存；无法直接给 CPU 传数据，必须先载入内存。

常见类型：

  1. HDD 机械硬盘：磁性存储，容量大、速度慢；
  2. SSD 固态硬盘：闪存芯片，读写快、抗震；
  3. 光盘 CD/DVD：激光读写，多用于影音资料；
  4. U 盘：便携闪存移动存储。
tip

一句话记忆

存储器速度断电是否保留典型用途
Cache最快否CPU 高频缓存
RAM快否运行中的程序
ROM慢是固件/BIOS
外存最慢是长期保存文件

9.4 输入/输出设备（I/O设备）

计算机和外界交互的桥梁。

9.4.1 输入设备（向电脑传数据）

键盘、鼠标、扫描仪、摄像头、麦克风。

9.4.2 输出设备（电脑向外输出结果）

显示器（LCD/OLED）、打印机、音箱、投影仪。

9.5 总线

连接 CPU、内存、外设的公共传输线路，统一传输数据、地址、控制信号。

9.5.1 三类总线

  1. 数据总线：传输运算数据，位数等于 CPU 字长；
  2. 地址总线：传输内存地址，位数决定最大寻址内存容量；
  3. 控制总线：传递读写、中断等控制信号。

9.5.2 特点

总线共享，同一时间仅一台设备发送数据、多台可接收；性能由总线宽度、频率决定。

9.6 系统软件

管理硬件、为应用软件提供运行环境。

9.6.1 操作系统 OS

最核心系统软件，管理软硬件资源、提供人机交互；Windows/macOS/Linux/Android/iOS。

9.6.2 语言处理程序

把高级语言转机器语言：

  • 编译器（C/C++）：一次性整体翻译；
  • 解释器（Python）：逐行实时执行；
  • 汇编程序：汇编语言转机器码。

9.6.3 DBMS 数据库管理系统

MySQL、Oracle，负责数据增删改查。

9.6.4 工具软件

杀毒、磁盘清理、备份工具等维护程序。

9.7 应用软件

面向用户特定需求，运行在操作系统之上：

  1. 办公软件：Word、Excel、PPT；
  2. 图形设计：PS、CAD；
  3. 多媒体：剪映、播放器；
  4. 行业专用：医疗、金融管理系统。

练习题（2 级单选风格）

  1. 下列软件中属于"系统软件"的是？
    • A. Microsoft Word
    • B. Windows 操作系统
    • C. 微信
    • D. Photoshop
  2. 关于 CPU，下列说法正确的是？
    • A. 负责长期存储文件
    • B. 由运算器和控制器组成
    • C. 即内存（RAM）
    • D. 属于输入设备
  3. 下列设备中属于"输入设备"的是？
    • A. 显示器
    • B. 打印机
    • C. 键盘
    • D. 音箱
  4. CPU 能直接访问、断电后数据丢失的存储部件是？
    • A. 硬盘
    • B. 内存（RAM）
    • C. 光盘
    • D. U 盘
  5. 计算机中负责在各部件之间传输数据、地址和控制的"高速公路"是？
    • A. 显卡
    • B. 总线
    • C. 电源
    • D. 散热器
参考答案（点击展开）
  1. B — 操作系统管理硬件与软件资源，属于系统软件；Word、微信、PS 都是应用软件。
  2. B — CPU 由运算器（算数逻辑单元）和控制器组成，是运算核心，不是存储器也不是 I/O 设备。
  3. C — 键盘把外界信息送进计算机，是输入设备；显示器、打印机、音箱都是输出设备。
  4. B — 内存（RAM）CPU 可直接访问且断电丢失；硬盘、光盘、U 盘属于外存，断电不丢但 CPU 不能直接访问。
  5. B — 总线（Bus）是连接 CPU、内存、外设并传输数据/地址/控制信号的通道。
