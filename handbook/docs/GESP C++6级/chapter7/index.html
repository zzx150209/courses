第55章 简单动态规划

本讲对应 GESP C++ 六级知识块 · 简单动态规划（一维动态规划、简单背包）

考核目标：掌握动态规划的核心思想（最优子结构、重叠子问题、状态转移方程、边界条件）；能使用代码解决一维动态规划问题（如斐波那契、爬楼梯、最大子数组和）与简单背包问题（0/1 背包、完全背包）。

核心知识点：

  • 解题五步：定义状态 → 推导转移 → 初始化边界 → 顺序计算 → 提取答案
  • 一维 DP：状态仅一个下标 dp[i]
  • 简单背包：0/1 背包（每件一次）、完全背包（每件无限）

动态规划(Dynamic Programming,简称DP)是一种通过分解复杂问题为重叠子问题，并利用子问题的解来高效求解原问题的算法思想。与递归相比，动态规划通过存储中间结果（即"记忆化"）避免了重复计算，显著提升了效率。

55.1 动态规划的基本概念

55.1.1 核心思想

动态规划的核心思想可概括为"分解问题、存储中间结果、利用子问题解求原问题解"：

  1. 重叠子问题：子问题之间存在重复，不同原问题拆分后会出现相同子问题。
  2. 最优子结构：原问题的最优解由子问题最优解构成，是DP成立基础。
  3. 状态转移方程：描述当前状态与前置状态的数学关系式。
  4. 边界条件：最小、无法再拆分的子问题解，作为计算起点。

55.1.2 解题标准步骤

  1. 定义状态：确定dp[i]/dp[i][j]代表的实际含义
  2. 推导状态转移方程
  3. 初始化边界条件
  4. 按依赖顺序迭代计算所有状态
  5. 从dp数组提取最终答案

55.2 一维动态规划

一维DP状态仅使用单下标dp[i]，适合线性递推类问题。

55.2.1 斐波那契数列

问题定义： F(0)=0F(0)=0F(0)=0 F(1)=1F(1)=1F(1)=1 F(n)=F(n−1)+F(n−2)n≥2F(n)=F(n-1)+F(n-2) \quad n≥2F(n)=F(n−1)+F(n−2)n≥2 求第nnn项数值。

动态规划解法： 状态定义：dp[i]dp[i]dp[i]表示第iii个斐波那契数 转移方程：dp[i]=dp[i−1]+dp[i−2]dp[i] = dp[i-1] + dp[i-2]dp[i]=dp[i−1]+dp[i−2] 边界：dp[0]=0,dp[1]=1dp[0]=0,\quad dp[1]=1dp[0]=0,dp[1]=1

#include <vector>
using namespace std;
int fibonacci(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    vector<int> dp(n + 1);
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}

空间优化（仅保留两个前置变量，空间复杂度降至O(1)O(1)O(1)）

int fibonacciOptimized(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    int a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}

55.2.2 爬楼梯问题

题意：每次可爬1阶或2阶，求登上nnn阶楼梯总方法数。 状态：dp[i]dp[i]dp[i]爬到第iii阶的方法数 转移：dp[i]=dp[i−1]+dp[i−2]dp[i] = dp[i-1] + dp[i-2]dp[i]=dp[i−1]+dp[i−2] 边界：dp[1]=1,dp[2]=2dp[1]=1,\quad dp[2]=2dp[1]=1,dp[2]=2

int climbStairs(int n) {
    if (n == 1) return 1;
    vector<int> dp(n + 1);
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}

55.2.3 最大子数组和

题意：给定整数数组，找出连续子数组的最大和（子数组至少一个元素） 状态：dp[i]dp[i]dp[i]以第iii个元素结尾的最大连续和 转移：dp[i]=max⁡(nums[i],dp[i−1]+nums[i])dp[i] = \max(nums[i], dp[i-1]+nums[i])dp[i]=max(nums[i],dp[i−1]+nums[i]) 边界：dp[0]=nums[0]dp[0] = nums[0]dp[0]=nums[0] 答案：dp数组内全部数值的最大值

#include <vector>
#include <algorithm>
using namespace std;
int maxSubArray(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n);
    dp[0] = nums[0];
    int maxSum = dp[0];
    for (int i = 1; i < n; i++) {
        dp[i] = max(nums[i], dp[i - 1] + nums[i]);
        maxSum = max(maxSum, dp[i]);
    }
    return maxSum;
}

空间优化版本

int maxSubArrayOptimized(vector<int>& nums) {
    int n = nums.size();
    int currentMax = nums[0];
    int maxSum = nums[0];
    for (int i = 1; i < n; i++) {
        currentMax = max(nums[i], currentMax + nums[i]);
        maxSum = max(maxSum, currentMax);
    }
    return maxSum;
}

55.3 简单背包问题

55.3.1 01背包

题意：共nnn件物品，每件仅取一次；物品重量w[i]w[i]w[i]、价值v[i]v[i]v[i]，背包最大容量CCC，求可装入最大总价值。 状态：dp[i][j]dp[i][j]dp[i][j]前iii件物品，容量jjj时最大价值 转移： dp[i][j]=max⁡(dp[i−1][j], j≥w[i]?dp[i−1][j−w[i]]+v[i]:0)dp[i][j] = \max(dp[i-1][j],\ j≥w[i] ? dp[i-1][j-w[i]]+v[i] : 0)dp[i][j]=max(dp[i−1][j], j≥w[i]?dp[i−1][j−w[i]]+v[i]:0) 边界：dp[0][j]=0,dp[i][0]=0dp[0][j]=0,\quad dp[i][0]=0dp[0][j]=0,dp[i][0]=0 最终结果：dp[n][C]dp[n][C]dp[n][C]

#include <vector>
#include <algorithm>
using namespace std;
int knapsack01(vector<int>& w, vector<int>& v, int C) {
    int n = w.size();
    vector<vector<int>> dp(n + 1, vector<int>(C + 1, 0));
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= C; j++) {
            dp[i][j] = dp[i - 1][j];
            if (j >= w[i - 1]) {
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i - 1]] + v[i - 1]);
            }
        }
    }
    return dp[n][C];
}

一维空间优化（逆序遍历，防止重复选取）

int knapsack01Optimized(vector<int>& w, vector<int>& v, int C) {
    int n = w.size();
    vector<int> dp(C + 1, 0);
    for (int i = 0; i < n; i++) {
        for (int j = C; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[C];
}

55.3.2 完全背包

题意：每件物品可无限选取，其余条件同01背包。 核心区别：遍历顺序改为正序，允许重复选取。 一维状态：dp[j]dp[j]dp[j]容量jjj的最大价值 转移：dp[j]=max⁡(dp[j],dp[j−w[i]]+v[i])dp[j] = \max(dp[j], dp[j-w[i]]+v[i])dp[j]=max(dp[j],dp[j−w[i]]+v[i])

int completeKnapsack(vector<int>& w, vector<int>& v, int C) {
    int n = w.size();
    vector<int> dp(C + 1, 0);
    for (int i = 0; i < n; i++) {
        for (int j = w[i]; j <= C; j++) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[C];
}

01背包与完全背包对比：

  1. 01背包：容量从大到小遍历，每件物品只能选1次
  2. 完全背包：容量从小到大遍历，每件可无限选取

55.4 动态规划常见优化策略

  1. 空间优化：二维dp压缩为一维，或只用少数变量存储前置状态（斐波那契、最大子数组）
  2. 滚动数组：仅保留最近k层状态，大幅降低空间开销
  3. 状态压缩：合并冗余状态，减少dp数组维度
  4. 剪枝：提前跳过不可能产生更优解的分支（如路径和超过目标直接终止）

练习题

  1. 动态规划能够高效解决问题的两个重要性质是（ ） A. 分治与递归 B. 最优子结构与重叠子问题 C. 贪心选择与局部最优 D. 随机化与并行

    答案与解析

    答案：B

    解析：动态规划成立的基石是"最优子结构"（原问题最优解由子问题最优解构成）和"重叠子问题"（不同原问题会重复用到相同子问题，可用记忆化避免重复计算）。贪心是另一类算法思想。

  2. 爬楼梯问题：每次可爬 1 阶或 2 阶，登上第 iii 阶的方法数 dp[i]dp[i]dp[i] 的转移方程是（ ） A. dp[i]=dp[i−1]×dp[i−2]dp[i] = dp[i-1] \times dp[i-2]dp[i]=dp[i−1]×dp[i−2] B. dp[i]=dp[i−1]+dp[i−2]dp[i] = dp[i-1] + dp[i-2]dp[i]=dp[i−1]+dp[i−2] C. dp[i]=max⁡(dp[i−1],dp[i−2])dp[i] = \max(dp[i-1], dp[i-2])dp[i]=max(dp[i−1],dp[i−2]) D. dp[i]=idp[i] = idp[i]=i

    答案与解析

    答案：B

    解析：到达第 iii 阶的最后一步要么从第 i−1i-1i−1 阶跨 1 步、要么从第 i−2i-2i−2 阶跨 2 步，因此方法数相加：dp[i]=dp[i−1]+dp[i−2]dp[i] = dp[i-1] + dp[i-2]dp[i]=dp[i−1]+dp[i−2]（与斐波那契同构）。

  3. 关于 0/1 背包与完全背包的一维空间优化写法，正确的容量遍历方向是（ ） A. 两者都从大到小遍历 B. 0/1 背包容量从大到小（防止重复选），完全背包从小到大（允许重复选） C. 两者都从小到大遍历 D. 容量方向无所谓

    答案与解析

    答案：B

    解析：0/1 背包每件只能选一次，需用上一轮（更小的 j−w[i]j-w[i]j−w[i]）的状态，所以容量必须从大到小逆序遍历，避免同一物品被重复装入；完全背包每件可无限取，需要本轮已更新过的状态，故容量从小到大正序遍历。

  4. 最大子数组和问题中，若定义 dp[i]dp[i]dp[i] 为"以第 iii 个元素结尾的连续子数组最大和"，其转移方程是（ ） A. dp[i]=dp[i−1]+nums[i]dp[i] = dp[i-1] + nums[i]dp[i]=dp[i−1]+nums[i] B. dp[i]=max⁡(nums[i], dp[i−1]+nums[i])dp[i] = \max(nums[i],\ dp[i-1] + nums[i])dp[i]=max(nums[i], dp[i−1]+nums[i]) C. dp[i]=max⁡(nums[i], dp[i−1])dp[i] = \max(nums[i],\ dp[i-1])dp[i]=max(nums[i], dp[i−1]) D. dp[i]=nums[i]−dp[i−1]dp[i] = nums[i] - dp[i-1]dp[i]=nums[i]−dp[i−1]

    答案与解析

    答案：B

    解析：以 iii 结尾的最大子数组，要么"接在前面的最优子数组后面"（值为 dp[i−1]+nums[i]dp[i-1]+nums[i]dp[i−1]+nums[i]），要么"从 iii 自己重新开始"（值为 nums[i]nums[i]nums[i]），取两者较大者，即 dp[i]=max⁡(nums[i], dp[i−1]+nums[i])dp[i] = \max(nums[i],\ dp[i-1] + nums[i])dp[i]=max(nums[i], dp[i−1]+nums[i])。
