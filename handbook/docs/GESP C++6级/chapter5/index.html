第53章 格雷编码

本讲对应 GESP C++ 六级知识块 · 基于树的编码（格雷编码）

考核目标：理解格雷编码"相邻仅一位不同、首尾也仅一位不同"的特性；掌握二进制与格雷码之间的相互转换；能用代码生成格雷码序列。

核心知识点：

  • 格雷码定义与特点（相邻性、循环性、唯一性）
  • 转换公式：格雷码 G=B⊕(B≫1)G = B \oplus (B \gg 1)G=B⊕(B≫1)，以及逆转换
  • 生成方法：二进制转换法、镜像反射法

格雷编码(Gray Code)是一种特殊的二进制编码方式，其核心特性是相邻的两个编码之间仅有一位二进制数不同，且首尾两个编码也满足这一特性(形成循环)。

53.1 格雷编码的基本概念

53.1.1 定义

格雷编码是一个二进制数字系统；其中任意两个连续的数值仅有一位二进制数不同，且第一个和最后一个数值也仅有一位不同(构成循环格雷码)。 示例：3位格雷编码序列为：000、001、011、010、110、111、101、100。 相邻编码对000与100第0位不同、001与011第1位不同、011与010第0位不同，以此类推。 首尾对比：000与100(第2位不同)，满足循环特性。

53.1.2 特点

  1. 相邻性：任意两个连续编码的二进制表示中，仅有一个bit位不同。
  2. 循环性：序列的第一个编码和最后一个编码也仅有一个bit位不同。
  3. 唯一性：nnn位格雷编码包含2n2^{n}2n个不同的编码，覆盖0到2n−12^{n}-12n−1的所有整数。
  4. 无歧义性：编码转换时，相邻状态的切换仅涉及一位变化，可减少信号干扰导致的歧义。

53.2 格雷编码的数学性质

53.2.1 二进制编码的转换关系

nnn位二进制数BBB (bn−1bn−2...b1b0)(b_{n-1} b_{n-2} ... b_{1} b_{0})(bn−1​bn−2​...b1​b0​) 与对应的格雷码GGG (gn−1gn−2...g1g0)(g_{n-1} g_{n-2} ... g_{1} g_{0})(gn−1​gn−2​...g1​g0​) 存在明确的转换规则： 二进制转格雷码：

  1. 最高位相同：gn−1=bn−1g_{n-1}=b_{n-1}gn−1​=bn−1​
  2. 其他位：gi=bi+1 XOR big_{i}=b_{i+1} \text{ XOR } b_{i}gi​=bi+1​ XOR bi​，i=0,1,...,n−2i=0,1,...,n-2i=0,1,...,n−2，其中XOR为异或运算(相同为0，不同为1)。
  3. 公式简化：G=B XOR (B≫1)G=B \text{ XOR } (B \gg 1)G=B XOR (B≫1)

格雷码转二进制：

  1. 最高位相同：bn−1=gn−1b_{n-1}=g_{n-1}bn−1​=gn−1​
  2. 其他位：bi=bi+1 XOR gib_{i}=b_{i+1} \text{ XOR } g_{i}bi​=bi+1​ XOR gi​，i=0,1,...,n−2i=0,1,...,n-2i=0,1,...,n−2。
  3. 公式实现：从最高位开始，逐位与格雷码对应位异或。

示例：二进制数B=1010B=1010B=1010(十进制10)转格雷码

B≫1=0101,G=1010 XOR 0101=1111B \gg 1=0101,\quad G=1010 \text{ XOR } 0101=1111B≫1=0101,G=1010 XOR 0101=1111

格雷码G=1111G=1111G=1111转二进制：

b3=1,b2=1 XOR 1=0,b1=0 XOR 1=1,b0=1 XOR 0=0b_{3}=1,\quad b_{2}=1 \text{ XOR } 1=0,\quad b_{1}=0 \text{ XOR } 1=1,\quad b_{0}=1 \text{ XOR } 0=0b3​=1,b2​=1 XOR 1=0,b1​=0 XOR 1=1,b0​=1 XOR 0=0

最终二进制B=1010B=1010B=1010(十进制10)。

53.2.2 递推性质

nnn位格雷编码可由n−1n-1n−1位格雷编码通过镜像反射法生成，体现递归特性： n=1n=1n=1时，格雷编码为[0,1]。 n>1n>1n>1时：

  1. 将n−1n-1n−1位格雷编码序列作为前半部分，每个编码前加0。
  2. 将n−1n-1n−1位格雷编码序列反转作为后半部分，每个编码前加1。
  3. 合并两部分得到nnn位格雷编码序列。

示例：n=2n=2n=2时，基于n=1n=1n=1的序列[0,1]生成： 前半部分(加0)：00,01。 后半部分(反转加1)：11,10。 合并后：[00, 01,11,10]。

53.3 格雷编码的生成方法

53.3.1 二进制转换法

利用转换公式G=B XOR (B≫1)G=B \text{ XOR } (B \gg 1)G=B XOR (B≫1)直接生成nnn位格雷编码序列。

#include <vector>
using namespace std;
vector<int> generateGrayCode (int n) {
    int size = 1 << n;
    vector<int> gray;
    for (int i=0;i<size; i++){
        gray.push_back(i ^ (i>>1));
    }
    return gray;
}

示例：n=3n=3n=3时，生成序列为[0, 1, 3,2,6,7,5,4]，对应二进制格雷码 [000, 001, 011, 010, 110, 111, 101, 100]。

53.3.2 镜像反射法

基于递推性质，通过递归生成格雷编码。

#include <vector>
#include <algorithm>
using namespace std;
vector<int> grayCode (int n) {
    vector<int> result;
    if (n==0){
        result.push_back(0);
        return result;
    }
    vector<int> prev = grayCode (n -1);
    result = prev;
    reverse (prev.begin(), prev.end());
    int add = 1 << (n -1);
    for (int num:prev){
        result.push_back(num + add);
    }
    return result;
}

示例：n=2n=2n=2时，递归生成过程为： n=1n=1n=1输出[0,1]。 镜像反转prev→[1,0]，加1<<1=21<<1=21<<1=2→[3,2]。 合并得[0,1,3,2]。

53.3.3 循环移位法

初始编码为0。每次向右循环移动1位，与原编码异或后得到下一个编码。重复2n−12^{n}-12n−1次，得到完整序列。

#include <vector>
using namespace std;
vector<int> grayCodeByShift(int n) {
    vector<int> gray;
    int size=1<<n;
    int current=0;
    for (int i=0;i<size; i++) {
        gray.push_back(current);
        int lsb=current&1;
        current = (current>>1)|(lsb<<(n -1));
        current ^= gray[0];
    }
    return gray;
}

53.4 应用场景

  1. 数字通信：减少信号传输噪声干扰，相邻编码仅切换一位，降低误码率。
  2. 机械控制：电机转角、旋转编码器使用格雷码，避免位置检测出现中间误判状态。
  3. 模拟-数字转换(ADC)：平滑模拟量转数字量的过渡，减少量化误差。
  4. 卡诺图(Kamaugh图)：单元格相邻规则与格雷编码匹配，方便逻辑化简。
  5. 测试与故障检测：利用单比特变化特性快速定位单比特错误。

练习题

  1. 关于 nnn 位格雷编码，下列说法错误的是（ ） A. 任意两个相邻编码之间仅有一位二进制位不同 B. 第一个编码与最后一个编码之间也仅有一位不同（循环性） C. nnn 位格雷码共有 2n2^n2n 个不同的编码 D. 相邻两个格雷码之间可能有两位不同

    答案与解析

    答案：D

    解析：格雷码的核心特性就是"相邻仅一位不同"，并且首尾也仅一位不同（构成循环）；nnn 位格雷码覆盖 000 到 2n−12^n-12n−1 共 2n2^n2n 个整数。D 与定义直接矛盾。

  2. 将二进制数 B=1010B=1010B=1010（十进制 10）转换为格雷码，结果是（ ） A. 1010 B. 1111 C. 0101 D. 1100

    答案与解析

    答案：B

    解析：由公式 G=B⊕(B≫1)G = B \oplus (B \gg 1)G=B⊕(B≫1)，有 B≫1=0101B \gg 1 = 0101B≫1=0101，G=1010⊕0101=1111G = 1010 \oplus 0101 = 1111G=1010⊕0101=1111。也可按位算：最高位相同 g3=1g_3=1g3​=1，其余 gi=bi+1⊕big_i = b_{i+1} \oplus b_igi​=bi+1​⊕bi​，得到 1111。

  3. 用镜像反射法由 n−1n-1n−1 位格雷码生成 nnn 位格雷码时，正确做法是（ ） A. 把 n−1n-1n−1 位序列整体加 1 B. 取 n−1n-1n−1 位序列作为前半部分（前补 0），将其反转后整体加 2n−12^{n-1}2n−1 作为后半部分（前补 1），再拼接 C. 直接把每个 n−1n-1n−1 位码左移一位 D. 随机生成 2n2^n2n 个码即可

    答案与解析

    答案：B

    解析：镜像反射法的步骤是：前半部分取 n−1n-1n−1 位序列（每个码前补 0），后半部分取 n−1n-1n−1 位序列的反转（每个码前补 1，即整体加 2n−12^{n-1}2n−1），拼接后即为 nnn 位格雷码。例如由 [0,1] 得到 [00,01,11,10]。

  4. 格雷编码常用于旋转编码器、ADC 等场景，主要原因是（ ） A. 它能表示更大的数值范围 B. 相邻状态只变化一位，可显著降低状态切换时的误码与干扰 C. 它比普通二进制运算更快 D. 它不需要任何转换

    答案与解析

    答案：B

    解析：在机械位置检测、模数转换等场景中，普通二进制在进位时有多位同时跳变，容易产生瞬间误码；格雷码相邻仅一位变化，能大幅降低这种过渡错误，因此被广泛采用。
