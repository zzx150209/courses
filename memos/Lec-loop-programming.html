循环结构程序设计

在编程过程中，有时我们会遇到这样一种情况，需要将一件事（或类似的事）执行很多遍。我们会写很多重复性的代码。例如输出 100 次 “hello world!”。我们可以手写 100 条 cout 语句。

1
cout<<"hello world!";
2
cout<<"hello world!";
3
...
4
...
5
cout<<"hello world!";

但当执行次数不是一个常量时，我们无法通过代码重复多遍来解决。而 循环结构 可以非常方便的解决以上两个问题。

for循环

基本语法

xxxxxxxxxx
3
1
for(定义循环变量并初始化;循环条件;更新循环变量){
2
    循环内容
3
}

在循环首次开始时，会初始化循环变量。

每次循环开始，会判断循环条件，如果为真，则执行循环内容，否则，结束循环。

每次循环结束，更新循环变量的值。

那么输出 100 次 “hello world!”，就可以简单的利用 for 循环实现。

xxxxxxxxxx
3
1
for(int i=1;i<=100;i++){
2
    cout<<"hello world!\n";
3
}

for 循环更适合知道具体循环次数的情况

例题: #Luogu0044. 【深基4.例2】找最小值

找最值是一个经典的问题，我们可以通过 “打擂台” 的方法解决。首先我们定义一个 “擂主” mn 并 初始化 (求最小值初始化要比所有值都大。反之，求最大值初始化要比所有值都小)。

我们遍历每一个数和 “擂主”进行比较，如果当前数 x 比 “擂主” 还要小。那么 x 就成为了新的 “擂主”。最后的 “擂主” 就一定是这些数的最小值。

break语句

我们知道，循环会在循环条件为假时停止。但有时，我们会想要遇到一些特殊情况提前结束循环，那么就可以使用 break 语句。通常搭配 if 语句使用。

示例：

while(1) 表示循环条件始终为真，这就是一个 死循环。当输入的 num=0 时，触法 break 语句，循环提前结束。

continue语句

同样的，有时我们遇到特殊情况不想执行循环语句，但使用 break 语句会使循环提前结束，后续循环也无法执行。这时候使用 continue 语句即可跳过当前情况，后续循环继续运行。

示例：输出 1 到 100 之间的偶数。

当 i 是奇数时，直接触发 continue 语句跳过此次循环，后续循环继续执行。

擅长用 continue语句能使你的代码结构更加清晰哦！
