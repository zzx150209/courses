数学符号与基础知识

数学符号

整除/同余理论符号

  1. 整除符号：x∣y，表示 x 整除 y，即 x 是 y 的因数。

  2. 取模符号：xmody，表示 x 除以 y 得到的余数。

  3. 互质符号：x⊥y，表示 x，y 互质。

  4. 最大公约数：gcd(x,y)，在无混淆意义的时候可以写作 (x,y)。

  5. 最小公倍数：lcm(x,y)，在无混淆意义的时候可以写作 [x,y]。

 

数论函数常见符号

求和符号：∑ 符号，表示满足特定条件的数的和。举几个例子：

  • ∑i=1ni 表示 1+2+⋯+n 的和。其中 i 是一个变量，在求和符号的意义下，i 通常是正整数或者非负整数（除非特殊说明）。这个式子的含义可以理解为：i 从 1 循环到 n，所有 i 的和。这个式子用代码的形式很容易表达。当然，学过简单的组合数学的同学都知道：

    ∑i=1ni=n(n+1)2

  • ∑S⊆T|S| 表示所有被 T 包含的集合的大小的和。

  • ∑p≤np⊥n1 表示的是 n 以内有多少个与 n 互质的数，即 φ(n)，φ 是欧拉函数。

求积符号：∏ 符号，表示满足特定条件的数的积。举几个例子：

  • ∏i=1ni 表示 n 的阶乘，即 n!。在组合数学常见符号中会讲到。

  • ∏i=1nai 表示 a1×a2×a3×⋯×an。

  • ∏x∣dx 表示 d 的所有因数的乘积。

在行间公式中，求和符号与求积符号的上下条件会放到符号的上面和下面，这一点要注意。

 

其他常见符号

  1. 阶乘符号 !，n! 表示 1×2×3×⋯×n。特别地，0!=1。

  2. 向下取整符号：⌊x⌋，表示小于等于 x 的最大的整数。常用于分数，比如分数的向下取整 ⌊xy⌋。

  3. 向上取整符号：⌈x⌉，与向下取整符号相对，表示大于等于 x 的最小的整数。

  4. 组合数：(xy)

  5. 第一类斯特林数：[xy]

  6. 第二类斯特林数：{xy}

基础知识

整除

对于两个整数 a,b，如果存在整数 k，使得 b=a×k 那么称 a 整除 b，记作 a∣b 。此时，a 是 b 的因数，b 是 a 的倍数。

设 a,b,c 均为整数，则有以下常用性质。

性质一：自身整除性

对于任意非零整数 a，都有 a∣a 因为 a=a×1。

性质二：传递性

若 a∣b, b∣c，则 a∣c。

性质三：线性组合性质

若 a∣b, a∣c 。则对于任意整数 x,y，都有 a∣(bx+cy)

特别地：a∣(b+c) 以及 a∣(b−c)

 

质数与合数

一个大于 1 的正整数，如果它的正因数只有 1 和它本身，那么称这个数为质数，也称为素数。

例如：

2,3,5,7,11,13,17,19,…

都是质数。

一个大于 1 的正整数，如果它除了 1 和自身以外还有其他正因数，那么称这个数为合数。

例如：

4,6,8,9,10,12 等都是合数。

注意：1 既不是质数，也不是合数。

最大公约数与最小公倍数

公约数

如果正整数 d 同时满足 d∣a 和 d∣b。那么称 d 是 a 和 b 的公约数。

例如：

12 和 18 的公约数有：1、2、3、6。

最大公约数

a 和 b 的所有公约数中最大的一个，称为 a 和 b 的最大公约数，记作 gcd(a,b)。

在不会产生混淆时，也可以写作 (a,b)

例如：

gcd(12,18)=6

互质

如果 gcd(a,b)=1，则称 a 和 b 互质，记作 a⊥b。

需要注意，互质并不表示两个数都是质数。

 

欧几里得算法

欧几里得算法也称为辗转相除法，用于快速计算两个整数的最大公约数。

其核心性质为：

gcd(a,b)=gcd(b,amodb)

原理说明

设 a=bq+r 其中 r=amodb。

如果一个数同时整除 a 和 b，那么它也一定整除 a−bq=r。反过来，如果一个数同时整除 b 和 r，那么它也一定整除 bq+r=a。

因此，a,b 的公约数与 b,r 的公约数完全相同，所以： gcd(a,b)=gcd(b,r)。

公倍数

如果正整数 m 同时满足 a∣m 和 b∣m 。那么称 m 是 a 和 b 的公倍数。

例如，4 的正倍数有：4,8,12,16,20,24,…

6 的正倍数有：6,12,18,24,30,…

因此，4 和 6 的公倍数有： 12,24,36,…

 

最小公倍数

a 和 b 的所有正公倍数中最小的一个，称为 a 和 b 的最小公倍数，记作 lcm(a,b)。

在不会产生混淆时，也可以写作 [a,b]。

例如：lcm(4,6)=12。

lcm(a,b)=abgcd(a,b)

为了防止溢出，通常写为：lcm=a/__gcd(a,b)*b。

 

算数基本定理

算术基本定理指出：

任意一个大于 1 的正整数，都可以分解成若干个质数的乘积，并且在不考虑质因数排列顺序的情况下，这种分解方式是唯一的。

因此，任意正整数 n>1 都可以唯一表示为：

n=p1a1p2a2⋯pkak

其中：

  • p1,p2,…,pk 是互不相同的质数；

  • a1,a2,…,ak 是正整数。

这种表示方式称为 n 的标准质因数分解式。

例如：

60=22×31×51

360=23×32×51

算数基本定理的推论

令 a=p1α1p2α2…pkαk，b=p1β1p2β2…pkβk 。

  • 推论1：a 是 b 的约数的 充要条件 是对于 1≤i≤k，满足 αi≤βi。即 a 中每个质数的幂次都不超过 b 的。

  • 推论2：(a,b)=p1δ1p2δ2…pkδk, 其中对于 1≤i≤k，δi=min(αi,βi)。 [a,b]=p1γ1p2γ2…pkγk, 其中对于 1≤i≤k，γi=max(αi,βi)。

  • 推论3：a 的正约数的个数为：(α1+1)(α2+1)…(αk+1)。

  • 推论4：a 的正约数之和为：(1+p11+p12+⋯+p1α1)∗(1+p21+p22+⋯+p2α2)∗⋯∗(1+pk1+pk2+⋯+pkαk)

    利用 等比数列求和公式 化简得：p1α1+1−1p1−1∗p2α2+1−1p2−1∗⋯∗pkαk+1−1pk−1
